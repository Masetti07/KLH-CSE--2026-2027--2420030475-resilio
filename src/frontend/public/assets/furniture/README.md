These 24 optional Kenney Furniture Kit GLBs supplement the eight original
procedural props. Existing IDs and original materials are retained.

Models load locally on placement, fit uniformly within catalogue dimensions,
and align to the floor. Invalid or missing models use a selectable placeholder.
Existing drag, move, rotate, delete, save and reload controls apply.
No remote decoders or assets are requested.

The drawer groups all props under Living Room, Bedroom, Kitchen & Dining,
Bathroom, Study & Decor, and Wall Decor. The original Home Props panel remains
available below the viewport.

Publisher, source, selected-file inventory and CC0 license information are in
[asset licenses](../../../../../docs/asset-licenses.md), with the original pack
license notice retained there. The full external pack and unused opening models
are not redistributed.

Manual checks: add models from each category; drag/move/rotate/delete; save and
reload a mixed design; block one GLB request to check the fallback. Also inspect
PERFORMANCE mode with shadows disabled.
